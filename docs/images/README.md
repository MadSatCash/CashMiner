# Screenshots / Capturas

These PNGs show the actual CashMiner HTML/JS interface served by the current
application with an isolated temporary Testnet3 wallet. They are browser
captures, not mockups or edited user screenshots. No user data directory,
wallet balance, recovery phrase or private key was used. The demonstration
wallet is empty, the miners are stopped and no explorer cycle is running.

- `cashminer-overview.png`: English overview, wallet and six mining controls.
- `cashminer-peer-explorer.png`: Spanish Peer Explorer controls and empty database.

Las capturas muestran la interfaz real con una billetera temporal vacía de
Testnet3. No utilizan datos del usuario ni resultados ficticios de minería.
La billetera y el perfil de navegador temporales se eliminan tras la captura.
